# 甩狗（Shuai Gou）— Game Design Brief v1

> 100% 還原 WC3 自製地圖核心玩法。KaMe、模式變體、新內容留 v2。

---

## 1. 概述

| 欄位 | 內容 |
|------|------|
| 類型 | 多人派對 / 鬼抓人 + 熱土豆 |
| 人數 | **最多 8 人連線**（可 2–8 人開局測試） |
| 單局時長 | 短局（目標 3–8 分鐘） |
| 平台 | **網頁**（Vite + Phaser 3 + Socket.io） |
| 鏡頭 | 俯視 2D（推測，依 WC3 地圖） |

### 玩家幻想

> 我必須在甩尾狗漂移撲過來之前，把球傳給隊友；越久不傳，狗越快，越來越來不及。

### 設計支柱

| # | 支柱 | 驗證方式 |
|---|------|----------|
| P1 | 燙手球 | 持球者心率上升、頻繁傳球 |
| P2 | 持球也可 Blink | 持球者仍可逃生，但 CD 與無球相同 |
| P3 | 持球時間 → 狗加速 | 拖時間明顯更危險 |
| P4 | 甩尾可讀 | 玩家能靠走位/卡邊緣讓狗繞圈 |
| P5 | 派對陷害 | 玩家故意傳向貼臉隊友 |

### 反支柱

- 不做蓄力 KaMe（v1）
- 不做飛毛腿 / 風火輪（v1）
- 不做障礙物、養成、道具

## 2. 核心循環

```text
隨機開球
    ↓
┌─────────────────────────────────────┐
│ 持球者被狗鎖定                       │
│  狗速 = f(持球時間) ↑               │
│  持球者：移動 + 右鍵傳球 + Blink（CD）│
│  無球者：移動 + Blink（CD）          │
└─────────────────────────────────────┘
    ↓ 傳球成功（飛行落地）
新持球者（壓力保留 90%）→ 狗改追新目標
    ↓
狗碰到持球者 → 死亡 → 觀戰
    ↓
最後存活者 → 勝利
```

## 3. 玩家狀態機

```text
                    ┌──────────┐
         開局/傳球   │  ALIVE   │
        ──────────► │  (無球)  │◄──────────┐
                    └────┬─────┘           │
                         │ 接到傳球         │ 傳出球
                         ▼                 │
                    ┌──────────┐           │
                    │  ALIVE   │───────────┘
                    │  (持球)  │
                    └────┬─────┘
                         │ 被狗碰到
                         ▼
                    ┌──────────┐
                    │   DEAD   │ → 觀戰
                    └──────────┘
```

### 3.1 ALIVE（無球）

| 能力 | 說明 |
|------|------|
| 移動 | 右鍵點地，角色走向目標點 |
| Blink | 可用，有冷卻時間 |
| 接球 | **不可主動接**；僅在被隊友右鍵選中時成為持球者 |
| 傳球 | 不可用 |

### 3.2 ALIVE（持球）

| 能力 | 說明 |
|------|------|
| 移動 | 右鍵點地（與無球同速 300） |
| 傳球 | 右鍵點**存活**玩家；不可點死人 |
| Blink | **可用**，與無球相同冷卻 |
| 接球 | N/A（已在持球） |

### 3.3 DEAD

- 無操作權限
- 攝影機跟隨存活玩家或自由觀戰（待定）
- 不可被傳球

## 4. 輸入與優先級

| 操作 | 輸入 | 條件 |
|------|------|------|
| 移動 | 右鍵點地 | 存活 |
| 傳球 | 右鍵點存活玩家 | 存活且持球 |
| Blink | 快捷鍵（建議 Space / B） | 存活且 CD 結束 |

**點擊優先級（持球時）：**

1. 若右鍵命中存活玩家 collider → **傳球**
2. 否則若右鍵命中地面 → **移動**

**點擊優先級（無球時）：**

- 右鍵點地 → 移動
- 右鍵點玩家 → 無效果（不可主動要球）

---

## 5. 傳球規則

| 規則 | 說明 |
|------|------|
| 目標 | 必須是存活玩家 |
| 禁止 | 死人、自己 |
| 軌跡 | **有飛行**：800 px/s 追目標當下位置；距離 ≤14px 落地才持球 |
| 飛行中 | 無人持球；不可傳球；狗追球；壓力繼續累加 |
| 接球後 | 立即成為持球者；狗改追新持球者；**壓力保留 90%**（不歸零） |
| 硬直 | **無接球硬直**；限制來自飛行時間與網路延遲 |
| Hover | 持球且球未在飛時，滑鼠移到隊友顯示「可傳球」；點選半徑 44px |

## 6. 狗（AI）

### 6.1 行為

- 永遠鎖定**球**：持球追持球者（近身略偏前方）；飛行追球
- 持球者死亡 → 全場停 2 秒 → 球從死亡位置飛向隨機存活者
- 僅在「持球者存活、持有球、球不在飛」時造成擊殺

### 6.2 速度模型

```text
speed(t) = baseSpeed + pressureSec × accelPerSecond

pressureSec 在持球與飛行中持續累加
傳球當下 pressureSec *= 0.9
無 maxSpeed
近身轉向隨「狗速／玩家速度」放大，避免高速轉彎半徑失控
```

| 參數 | 現行值 | 備註 |
|------|----------|------|
| baseSpeed | 135 | 玩家 300 |
| accelPerSecond | 56 | HUD 滿格對應 10 秒，實際無上限 |
| maxSpeed | 無 | 用轉向 agility 避免無限甩尾 | |

### 6.3 甩尾物理（Type A — 飄移）

**設計意圖：** 狗直線追擊快，急轉彎時因慣性外甩，路徑可預判。

**實作要點：**

```text
desiredVelocity = normalize(target - pos) × speed(t)
actualVelocity  = lerp(actualVelocity, desiredVelocity, turnRate) 
                  // 或使用角速度上限 + 側向摩擦力

constraints:
  - maxTurnRate（度/秒）隨 speed 略增或略減
  - 高速時轉彎半徑變大 → 「甩尾」感
  - 視覺：狗頭朝向目標，身體可沿速度滑行（朝向與速度分離）
```

**玩家技巧：**

- 貼 arena 邊緣跑，逼狗大角度轉彎
- 在狗外甩時傳球，新目標在狗反方向 → 狗需大角度折返

### 6.4 擊殺判定

- 狗 collision body 與**持球者** overlap → 持球者死亡
- 狗穿過無球者：**不擊殺**（待定，需確認原版）

## 7. 對局流程

```text
1. 大廳 / 匹配（人數到齊）
2. Countdown 3…2…1
3. 隨機選一存活玩家賦予球
4. 自由遊玩
5. 僅剩 1 人 → 勝利畫面 → 重開
```

| 階段 | 說明 |
|------|------|
| 開球 | uniform random among alive players |
| 中途加入 | v1 不做 |
| 平手 | 不適用（至剩 1 人） |

## 10. 已確認規格（2026-08-20）

| # | 問題 | 決策 |
|---|------|------|
| Q1 | 平台 | **網頁**（Vite + Phaser + Socket.io） |
| Q2 | 人數 | **最多 8 人連線** |
| Q3 | 持球者移動速度 | **與無球相同** |
| Q4 | 死者球權 | 持球者被殺 → 球**隨機給一名存活者** |
| Q5 | 狗碰無球者 | 無傷害（預設） |
| Q6 | Blink | CD **2.8s**，距離 **160px**；持球可用 |
| Q7 | 加速曲線 | 線性、**無 maxSpeed**；傳球保留 90% 壓力 |
| Q8 | 連線 | 伺服器權威；物理 60Hz、快照 30Hz、事件即時送 |
| Q9 | 操控 | **僅右鍵**移動／傳球；Space Blink（無 WASD） |
| Q10 | 傳球 | 飛行彈道，落地才可再傳 |
