# 甩狗 Playtest Observation

## 目的

用不熟悉規則的玩家觀察兩件事：

1. 玩家是否能不看外部說明完成單人練習房三步驟。
2. 玩家是否能在第一局多人遊戲中理解「持球者是狗的目標」、傳球時機與 Blink。

這份表記錄行為，不在測試途中教玩家。若玩家卡住，先記錄卡點，再於測試結束後詢問原因。

## 測試條件

- Build／commit：
- 測試日期：
- 玩家代號：
- 是否玩過同類型遊戲：
- 裝置／瀏覽器：
- 輸入方式：滑鼠右鍵、Space
- 測試 URL：
- 是否使用月影庭：是／否

## A. 單人練習房

請只說：「請試著把這個練習完成。」不要補充操作方法。

| 步驟 | 玩家是否自行完成 | 卡住秒數 | 是否需要提示 | 玩家原話／行為 |
|---|---:|---:|---:|---|
| 進入練習房 |  |  |  |  |
| 1／3 走位 |  |  |  |  |
| 2／3 Blink |  |  |  |  |
| 3／3 傳球 |  |  |  |  |
| 完成後知道如何回大廳 |  |  |  |  |

### 練習房通過條件

- 不依賴外部說明完成 3／3。
- 每一步第一次卡住不超過 15 秒，或玩家能自行重新閱讀提示後繼續。
- 完成後能說出正式對局的主要目標與三個操作。

## 限制

開發者自己完成流程、截圖與自動化 smoke 不能取代這份觀察；至少需要一名不熟悉規則的玩家，並記錄完整測試路徑。
