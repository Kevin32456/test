# 角色 Sprite

如要用外部 PNG 取代程式繪製的 8 名像素角色，請使用以下檔名：

| 檔名 | 角色 |
|------|------|
| `char-hat.png` | 紳士 |
| `char-gauntlet.png` | 拳手 |
| `char-spike.png` | 少年 |
| `char-coat.png` | 旅人 |
| `char-ninja.png` | 忍者 |
| `char-miko.png` | 巫女 |
| `char-mechanic.png` | 機工師 |
| `char-captain.png` | 船長 |

建議透明背景 PNG。放好後重新整理頁面即可，無需改程式。
