# 甩狗（Shuai Gou） v0.2.0

《魔獸爭霸 III》自製地圖「甩狗」的網頁版還原：4 人連線、鬼抓人 + 熱土豆。

## 規則摘要

- 狗追**球**（持球時追玩家正面；傳球飛行中追球）
- 持球越久狗越快，轉彎有甩尾飄移
- 右鍵點地移動；持球時右鍵點活人傳球（有球路動畫）
- 持球者不能 Blink；無球者可 Blink（有 CD）
- 被狗碰到（持球時）出局；最後存活者獲勝

## 執行

```bash
npm install
npm run dev
```

- 前端：http://127.0.0.1:4317
- 伺服器：4318（Socket.io）

開 4 個分頁加入同一房間即可遊玩。滿 4 人自動開局，或至少 2 人可手動開始。
